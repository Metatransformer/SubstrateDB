# Vercel-integrated runtime distribution

Substrate starts as an open-source project. If the engine proves useful, a hosted product may follow with an Upstash-style Vercel integration provisioning documents, queues, cache, vectors, scheduling, and WebSockets together. This prioritizes a useful independently deployable engine over building a cloud business first; hosting and integration remain conditional future work. A future integration should isolate preview environments and disable production schedules and external job delivery there by default. The engine does not run inside Vercel Functions. License choice, hosting architecture, pricing, and preview provisioning mechanisms remain open.
