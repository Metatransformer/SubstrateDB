# WP03 — durable worker state machine

Implement shared CONTRACT.md. You are not alone; preserve other edits. ONLY allowed files src/jobs.rs and tests/jobs.rs. Changing/creating anything else is failure, stop/report if needed. No git add/commit, no unrelated formatting/refactors, shared data append-only. Before/after add durable jobs state only; no HTTP server/scheduler.

Export execute/is_mutation. Jobs scoped by Kv namespace/partition. Operations:
job.enqueue {id,queue,payload,available_at_ms?:u64,max_attempts?:u32,lease_ms?:u64,ordering_key?:string,delivery?:{url:string},expires_at_ms?:u64}; validate queue/id, checked time arithmetic, finite bounded retries (default 5), lease default 30000 bounds 100..3600000. Idempotent only same initial job content; changed reuse conflict. Record stable enqueue order sequence.
job.claim {queue,worker,lease_ms?:u64,delivery_mode?:"pull"|"http"}; choose due ready jobs or expired claims respecting ordering-key serialization. Default pull must exclude HTTP destinations; http only HTTP. At claim increment attempt and monotonic lease generation; token deterministic from command.request_id+attempt sufficient (request IDs supplied by trusted server), persist worker and deadline. Return {job:record,receipt:string} or {job:null}. Reclaimed job invalidates previous receipt; exhausted attempts mark dead_letter, expired jobs mark expired; never silently delete. Define ordered terminal failures unblock next, nonterminal retries block. Inspect other same ordering-key jobs to avoid concurrent claims even across queues (or explicitly queue-scope with docs). Stable enqueue ordering.
job.ack {id,receipt}; only current unexpired lease; mark completed; repeated ack same receipt returns result; stale ack conflicts. job.nack {id,receipt,retryable?:bool,delay_ms?:u64}; retryable with attempts left -> ready future with bounded exponential backoff deterministic jitter; else dead_letter. job.heartbeat {id,receipt,lease_ms?:u64} extends unexpired lease. job.get {id}; job.list {queue?,status?,limit?}; job.cancel {id}; job.retry {id} explicit deadletter restart; job.pause {queue}; job.resume {queue}. Paused queue never claims; restore will set pause flags. Guard no-retry (max_attempts=1) and cancellation, expired ack. Delivery URL http/https validation using reqwest::Url; no outgoing requests here.

Events emitted for job transitions via store::emit. Ensure cmd.now_ms only clock. Tests using MemoryKv: claim/ack, stale receipt after timeout/reclaim, retry exhaustion, ordering isolation, pause, cancel/expiry, HTTP vs pull selection, and repeated enqueue behavior. Module actions not recognized error. Must not drop accepted work due event.trim. No delegation.
